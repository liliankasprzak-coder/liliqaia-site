Modelo 01 — Agente de FAQ
Problema que resolve
Perguntas repetitivas consumindo tempo do atendimento
Público possível
Qualquer negócio com atendimento por WhatsApp/Instagram
Função
Responder as dúvidas mais comuns automaticamente
Informações necessárias
Lista de perguntas frequentes com respostas, preços, horário de funcionamento
Estrutura de instruções
PAPEL: atendente de FAQ do [negócio]. TAREFA: responder dúvidas da lista de FAQ. LIMITE: se não estiver na lista, admitir e oferecer encaminhamento.
Testes sugeridos
"Qual o horário de vocês?" / pergunta fora da FAQ, tipo "vocês fazem entrega em outra cidade?"
Como adaptar
Troque a lista de FAQ pelas perguntas reais do novo negócio (Prompt 08, Central de Recursos)
Demonstração sugerida
Print de 2-3 perguntas comuns sendo respondidas em segundos
Modelo 02 — Agente de Pré-atendimento
Problema que resolve
Tempo perdido triando quem chega antes de saber o que precisa
Público possível
Negócios com múltiplos setores/serviços (clínicas, escritórios, agências)
Função
Entender o que a pessoa precisa e direcionar pro setor certo
Informações necessárias
Lista de setores/serviços disponíveis e critério de direcionamento
Estrutura de instruções
PAPEL: recepcionista virtual. TAREFA: perguntar o motivo do contato e classificar em uma das categorias. SAÍDA: resumo curto pra quem for atender.
Testes sugeridos
Pedido claro de um setor específico / pedido vago que exige pergunta de esclarecimento
Como adaptar
Ajuste a lista de setores/categorias pro negócio específico
Demonstração sugerida
Print mostrando a triagem de 2 pedidos diferentes
Modelo 03 — Agente de Catálogo
Problema que resolve
Cliente com dúvida específica sobre um produto/serviço
Público possível
Lojas, negócios com catálogo de produtos ou serviços variados
Função
Apresentar itens do catálogo e responder dúvidas específicas
Informações necessárias
Lista de produtos/serviços com preço, disponibilidade e características
Estrutura de instruções
PAPEL: consultor de catálogo. TAREFA: recomendar itens com base no que o cliente descreve precisar. REGRA: nunca recomendar item fora de estoque.
Testes sugeridos
Pergunta sobre item específico / pedido de recomendação vaga ("quero algo pra presente")
Como adaptar
Atualize a lista de itens sempre que o catálogo mudar
Demonstração sugerida
Print mostrando uma recomendação personalizada
Modelo 04 — Agente de Briefing
Problema que resolve
Ida e volta excessiva coletando informação antes de iniciar um trabalho
Público possível
Freelancers, agências, prestadores de serviço sob demanda
Função
Coletar as informações certas de forma estruturada, numa única conversa
Informações necessárias
Lista das perguntas essenciais pra iniciar o tipo de trabalho
Estrutura de instruções
PAPEL: assistente de briefing. TAREFA: fazer as perguntas da lista, uma de cada vez, e organizar as respostas num resumo final.
Testes sugeridos
Cliente que responde de forma incompleta / cliente que já manda tudo de uma vez
Como adaptar
Troque as perguntas conforme o tipo de trabalho (design, texto, consultoria...)
Demonstração sugerida
Print da conversa completa até o resumo final gerado
Modelo 05 — Agente de Conteúdo
Problema que resolve
Bloqueio criativo na hora de postar com frequência
Público possível
Criadores, pequenos negócios que precisam postar regularmente
Função
Transformar um tema solto em 3-5 ideias estruturadas de conteúdo
Informações necessárias
Tom de voz da marca, formatos usados (reels, carrossel, post)
Estrutura de instruções
PAPEL: estrategista de conteúdo. TAREFA: gerar ideias com título + gancho + estrutura, no tom de voz definido.
Testes sugeridos
Tema amplo ("autocuidado") / tema muito específico de nicho
Como adaptar
Ajuste o tom de voz e os formatos preferidos por marca
Demonstração sugerida
Print de 3 ideias geradas a partir de um único tema
Modelo 06 — Agente Editorial
Problema que resolve
Falta de planejamento gerando repetição de temas nas redes
Público possível
Times de marketing, criadores com publicação frequente
Função
Organizar pauta e calendário editorial do mês
Informações necessárias
Temas já publicados recentemente, datas importantes do nicho
Estrutura de instruções
PAPEL: editor de pauta. TAREFA: montar um calendário semanal evitando repetição de temas recentes.
Testes sugeridos
Pedido de pauta pro mês inteiro / ajuste de uma pauta já existente
Como adaptar
Atualize a lista de temas já publicados a cada uso
Demonstração sugerida
Print de um calendário semanal gerado
Modelo 07 — Agente de Documentos
Problema que resolve
Tempo gasto lendo e organizando documentos longos
Público possível
Escritórios, consultorias, qualquer negócio com muito documento
Função
Resumir e sugerir organização de documentos recebidos
Informações necessárias
Categorias de arquivamento usadas pelo negócio
Estrutura de instruções
PAPEL: organizador de documentos. TAREFA: resumir o documento colado e sugerir em qual categoria arquivar.
Testes sugeridos
Documento longo e denso / documento curto e ambíguo
Como adaptar
Ajuste as categorias de arquivamento pro sistema do negócio
Demonstração sugerida
Print de um documento longo sendo resumido em poucas linhas
Modelo 08 — Agente de Procedimentos
Problema que resolve
Repetir a mesma explicação de processo pra cada funcionário novo
Público possível
Negócios com equipe e rotatividade, franquias
Função
Explicar processos internos passo a passo
Informações necessárias
Lista de procedimentos internos documentados
Estrutura de instruções
PAPEL: manual de procedimentos interativo. TAREFA: explicar o processo perguntado, passo a passo, de forma didática.
Testes sugeridos
Pergunta sobre processo existente / pergunta sobre processo não documentado
Como adaptar
Atualize sempre que um processo interno mudar
Demonstração sugerida
Print explicando um processo comum passo a passo
Modelo 09 — Agente de Preparação Comercial
Problema que resolve
Time de vendas indo pra reunião sem contexto suficiente
Público possível
Times comerciais, consultores, vendedores
Função
Organizar informações do cliente antes do atendimento/venda
Informações necessárias
Catálogo, argumentos de venda, objeções comuns
Estrutura de instruções
PAPEL: preparador comercial. TAREFA: a partir dos dados do cliente, montar um briefing rápido com possíveis objeções e argumentos.
Testes sugeridos
Cliente com histórico simples / cliente com objeção conhecida
Como adaptar
Atualize os argumentos de venda conforme o produto/serviço
Demonstração sugerida
Print de um briefing pronto pra um atendimento
Modelo 10 — Agente Educativo
Problema que resolve
Cliente sem entender algo técnico antes de decidir comprar
Público possível
Negócios que vendem algo técnico ou pouco conhecido
Função
Explicar conceitos de forma didática, tirando dúvidas
Informações necessárias
Glossário de termos técnicos do negócio, traduzidos pra linguagem simples
Estrutura de instruções
PAPEL: educador. TAREFA: explicar o conceito perguntado com exemplos simples, sem jargão.
Testes sugeridos
Termo técnico comum / pergunta que exige analogia simples
Como adaptar
Use o Prompt 35 (Central de Recursos) pra traduzir novos termos técnicos
Demonstração sugerida
Print de um termo técnico sendo explicado de forma simples
