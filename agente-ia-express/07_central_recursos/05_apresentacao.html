Categoria 05

Prompts de Apresentação

Use pra transformar o que você construiu em algo que vende.

PROMPT 41

Explicar o agente em uma frase simples

Quando usarMódulo 5, ao montar a oferta
Preencher[INSTRUÇÕES DO AGENTE]
Resuma o que este agente faz em uma frase que qualquer pessoa leiga entenda, sem usar a palavra "IA" ou termos técnicos: [INSTRUÇÕES DO AGENTE]

Exemplo: cole as instruções completas do Bella Bot.

Próximo passo: use essa frase no campo "Solução" do Gerador de Oferta.

PROMPT 42

Criar um case a partir de um projeto

Quando usarMódulo 6
Preencher[DADOS DO PROJETO]
Com base nestes dados: [DADOS DO PROJETO], monte um case seguindo a estrutura CONTEXTO, PROBLEMA, AGENTE, COMO FUNCIONA, DEMONSTRAÇÃO, POSSÍVEIS APLICAÇÕES. Se não houver cliente real, sinalize como "Projeto Demonstrativo".

Exemplo: cole a Ficha do Primeiro Agente preenchida.

Próximo passo: adicione um print/gif de demonstração real.

PROMPT 43

Montar o roteiro de uma demonstração

Quando usarMódulo 6
Preencher[AGENTE], [PROBLEMA QUE RESOLVE]
Escreva um roteiro curto (5 falas) demonstrando o agente [AGENTE] resolvendo o problema: [PROBLEMA QUE RESOLVE], seguindo: problema → entrada → agente trabalhando → saída → utilidade.

Exemplo: "...Bella Bot... demora de resposta de preço..."

Próximo passo: grave um print/gif seguindo esse roteiro.

PROMPT 44

Transformar um recurso técnico em benefício

Quando usarAo escrever qualquer material de venda
Preencher[RECURSO TÉCNICO]
Transforme este recurso técnico em um benefício que o cliente entenda na prática: [RECURSO TÉCNICO]. Formato: "Isso significa que você..."

Exemplo: "...o agente responde em menos de 5 segundos..."

Próximo passo: use essas frases na Apresentação Comercial.

PROMPT 45

Estruturar uma apresentação comercial completa

Quando usarMódulo 6, antes de uma reunião de venda
Preencher[CASE], [PREÇO]
Com base neste case: [CASE] e este preço: [PREÇO], monte o texto de 6 slides pra uma apresentação comercial curta e direta.

Exemplo: cole o Template de Case preenchido.

Próximo passo: monte os slides visualmente (Canva, PowerPoint ou Google Slides).

PROMPT 46

Escrever a legenda de um post mostrando o agente

Quando usarAo divulgar um case nas redes sociais
Preencher[CASE RESUMIDO]
Escreva uma legenda curta de Instagram/LinkedIn mostrando este case: [CASE RESUMIDO], com um gancho no início e uma chamada pra ação no fim.

Exemplo: cole o resumo do case do Bella Bot.

Próximo passo: publique junto com o print/gif de demonstração.

PROMPT 47

Responder objeções comuns sobre preço/valor

Quando usarAo se preparar pra uma negociação
Preencher[OBJEÇÃO], [CASE]
Um possível cliente disse: "[OBJEÇÃO]". Considerando este case: [CASE], escreva uma resposta que reforça o valor sem ser defensiva.

Exemplo: "...está caro, dá pra fazer isso de graça no ChatGPT..."

Próximo passo: pratique a resposta em voz alta antes da reunião.

PROMPT 48

Criar um resumo de 1 parágrafo pro portfólio

Quando usarBônus 3 — Portfólio Express
Preencher[CASE COMPLETO]
Resuma este case completo em um único parágrafo curto e impactante pra usar no meu portfólio: [CASE COMPLETO]

Exemplo: cole o Template de Case do Bella Bot preenchido.

Próximo passo: adicione ao Portfólio Express.

PROMPT 49

Escrever uma mensagem de prospecção fria

Quando usarPra abordar um possível cliente pela primeira vez
Preencher[TIPO DE NEGÓCIO], [CASE PARECIDO]
Escreva uma mensagem curta de WhatsApp pra abordar o dono de um [TIPO DE NEGÓCIO] pela primeira vez, mencionando um case parecido: [CASE PARECIDO]. Tom direto, sem parecer spam.

Exemplo: "...uma barbearia... mencionando o case do salão..."

Próximo passo: personalize com o nome do negócio antes de enviar.

PROMPT 50

Preparar respostas pra dúvidas frequentes sobre o produto

Quando usarAntes de divulgar a oferta publicamente
Preencher[SEU AGENTE/OFERTA]
Liste 5 perguntas que um possível cliente provavelmente teria sobre esta oferta: [SEU AGENTE/OFERTA], com uma resposta curta pra cada.

Exemplo: cole o Gerador de Oferta preenchido.

Próximo passo: tenha essas respostas prontas antes de qualquer reunião.
