Categoria 04

Prompts de Adaptação

Use pra reaproveitar um agente pronto em vez de começar do zero a cada cliente novo.

PROMPT 31

Adaptar um agente pra outro nicho

Quando usarMódulo 3, ao mudar de nicho
Preencher[INSTRUÇÕES ATUAIS], [NOVO NICHO]
Adapte estas instruções: [INSTRUÇÕES ATUAIS] para funcionar no nicho de [NOVO NICHO], mantendo a mesma estrutura e mudando só o que for específico do negócio.

Exemplo: "...do Bella Bot (salão) para uma barbearia..."

Próximo passo: rode a Bateria de Testes na versão adaptada.

PROMPT 32

Adaptar a linguagem/tom pra um público diferente

Quando usarQuando o público muda de perfil
Preencher[TEXTO ATUAL], [NOVO PÚBLICO]
Reescreva este texto de resposta: [TEXTO ATUAL] com um tom adequado para [NOVO PÚBLICO], mantendo a mesma informação.

Exemplo: "...de um tom descontraído pra um tom mais formal, público: advogados..."

Próximo passo: atualize a seção FORMATO DE SAÍDA com o novo tom.

PROMPT 33

Adaptar o contexto mantendo a mesma estrutura

Quando usarAo reaproveitar um agente pra cliente novo
Preencher[CONTEXTO ANTIGO], [INFORMAÇÕES NOVAS]
Este era o contexto de um agente: [CONTEXTO ANTIGO]. Substitua pelas informações do novo negócio: [INFORMAÇÕES NOVAS], mantendo a mesma organização por categorias.

Exemplo: troque preços/horários do salão pelos de uma nova barbearia.

Próximo passo: confira se sobrou alguma informação antiga por engano.

PROMPT 34

Adaptar a tarefa principal do agente

Quando usarAo mudar de projeto (ex: A para B, Módulo 3)
Preencher[AGENTE ATUAL], [NOVA TAREFA]
Este agente hoje faz: [AGENTE ATUAL]. Adapte as instruções pra que a tarefa principal passe a ser: [NOVA TAREFA]. O que precisa mudar em CONTEXTO e REGRAS?

Exemplo: "...de responder FAQ para gerar ideias de conteúdo..."

Próximo passo: teste se a mudança de tarefa não quebrou nenhuma regra antiga.

PROMPT 35

Traduzir jargão técnico pra linguagem simples

Quando usarNegócios técnicos (jurídico, saúde, TI)
Preencher[TEXTO TÉCNICO]
Reescreva este texto técnico numa linguagem simples, que qualquer cliente leigo entenda: [TEXTO TÉCNICO]

Exemplo: cole um procedimento jurídico ou médico cheio de termos técnicos.

Próximo passo: use a versão simples no CONTEXTO do agente educativo.

PROMPT 36

Adaptar um agente de atendimento pra virar comercial

Quando usarAo evoluir de Projeto A pra Projeto D (Módulo 3)
Preencher[AGENTE DE ATENDIMENTO]
Este é um agente de atendimento: [AGENTE DE ATENDIMENTO]. Adapte pra que ele também colete informações de venda e monte um briefing comercial pro time humano.

Exemplo: cole as instruções do Bella Bot.

Próximo passo: adicione a nova TAREFA sem remover a função original.

PROMPT 37

Adaptar regras sazonais (ex: feriado, promoção)

Quando usarDatas especiais, mudanças temporárias
Preencher[REGRAS ATUAIS], [SITUAÇÃO SAZONAL]
Considerando a situação sazonal: [SITUAÇÃO SAZONAL], quais ajustes temporários eu deveria fazer nestas regras? [REGRAS ATUAIS]

Exemplo: "...feriado prolongado, salão fechado por 3 dias..."

Próximo passo: lembre de reverter a mudança depois que a situação passar.

PROMPT 38

Adaptar pra regionalismos e gírias locais

Quando usarNegócios muito regionais/locais
Preencher[TEXTO ATUAL], [REGIÃO]
Ajuste este texto pra soar natural pra um público de [REGIÃO], sem exagerar em gírias: [TEXTO ATUAL]

Exemplo: "...interior de Minas Gerais..."

Próximo passo: teste com alguém da região se soou natural ou forçado.

PROMPT 39

Adaptar um agente pronto pra um cliente novo (branding)

Quando usarAo reaproveitar um dos 10 Agentes Iniciais
Preencher[AGENTE MODELO], [DADOS DO CLIENTE]
Use este agente como modelo: [AGENTE MODELO]. Adapte com os dados do novo cliente: [DADOS DO CLIENTE], incluindo nome do negócio em todas as menções.

Exemplo: use o Agente de FAQ da Biblioteca (Bônus 1) como base.

Próximo passo: confira se não sobrou nenhuma menção ao negócio antigo.

PROMPT 40

Identificar o que NÃO deve mudar ao adaptar

Quando usarAntes de qualquer adaptação grande
Preencher[INSTRUÇÕES ATUAIS]
Nestas instruções: [INSTRUÇÕES ATUAIS], marque quais partes são específicas de UM negócio (mudam sempre) e quais são estruturais (não deveriam mudar ao adaptar pra outro cliente).

Exemplo: cole as instruções completas de qualquer agente já pronto.

Próximo passo: use essa divisão pra criar seu próprio template reutilizável.
