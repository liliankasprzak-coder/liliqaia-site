Categoria 06

Prompts de Operação

Use no dia a dia de manter e entregar projetos com organização.

PROMPT 51

Criar um briefing de cliente completo

Quando usarPrimeira conversa com um cliente novo
Preencher[RESPOSTAS DO CLIENTE]
Organize estas respostas do cliente num briefing estruturado, pronto pra eu usar na hora de montar o agente: [RESPOSTAS DO CLIENTE]

Exemplo: cole respostas soltas de um formulário ou conversa.

Próximo passo: use pra preencher a Ficha do Primeiro Agente do cliente.

PROMPT 52

Documentar as instruções de um agente

Quando usarDepois de finalizar um agente
Preencher[INSTRUÇÕES FINAIS]
Crie uma versão documentada destas instruções: [INSTRUÇÕES FINAIS], com um resumo no topo explicando o que o agente faz, pra eu consultar rápido no futuro.

Exemplo: cole as instruções finais e testadas do Bella Bot.

Próximo passo: salve no seu local de projetos (Módulo 00).

PROMPT 53

Escrever um checklist de entrega personalizado

Quando usarAntes de entregar pro cliente
Preencher[ESCOPO DO PROJETO]
Com base neste escopo: [ESCOPO DO PROJETO], crie um checklist de entrega específico, cobrindo tudo que precisa estar pronto antes de considerar o projeto finalizado.

Exemplo: cole o Template de Escopo preenchido.

Próximo passo: só entregue depois de marcar todos os itens.

PROMPT 54

Revisar um agente periodicamente

Quando usarRevisão mensal de manutenção
Preencher[INSTRUÇÕES ATUAIS], [MUDANÇAS NO NEGÓCIO]
Estas são as instruções atuais: [INSTRUÇÕES ATUAIS]. O negócio mudou o seguinte: [MUDANÇAS NO NEGÓCIO]. O que precisa ser atualizado?

Exemplo: "...preços reajustados, novo profissional contratado..."

Próximo passo: atualize e rode a Bateria de Testes de novo.

PROMPT 55

Atualizar a base de conhecimento com informação nova

Quando usarSempre que surgir informação nova
Preencher[CONTEXTO ATUAL], [INFORMAÇÃO NOVA]
Insira esta informação nova: [INFORMAÇÃO NOVA] dentro deste contexto existente, na categoria certa, sem duplicar nada: [CONTEXTO ATUAL]

Exemplo: "...novo serviço de alisamento adicionado ao cardápio..."

Próximo passo: confirme que a informação antiga não ficou contraditória.

PROMPT 56

Organizar múltiplos agentes de vários clientes

Quando usarQuando já tem 3+ projetos ativos
Preencher[LISTA DE PROJETOS]
Sugira uma estrutura de pastas/nomenclatura pra organizar estes projetos: [LISTA DE PROJETOS], facilitando achar qualquer um rapidamente.

Exemplo: liste nome do cliente + tipo de agente + data de entrega.

Próximo passo: aplique a estrutura sugerida no seu Drive/Notion.

PROMPT 57

Escrever instruções de handoff pra outra pessoa assumir

Quando usarAo delegar ou transferir um projeto
Preencher[DETALHES DO PROJETO]
Escreva um documento de transferência (handoff) explicando este projeto pra outra pessoa assumir sem perder contexto: [DETALHES DO PROJETO]

Exemplo: cole o case completo + histórico de ajustes feitos.

Próximo passo: revise junto com a pessoa antes de transferir de vez.

PROMPT 58

Criar um registro de mudanças (changelog)

Quando usarToda vez que ajustar um agente já entregue
Preencher[MUDANÇA FEITA], [MOTIVO]
Escreva uma linha de changelog curta e clara pra esta mudança: [MUDANÇA FEITA], motivo: [MOTIVO]. Formato: data — o que mudou — por quê.

Exemplo: "...adicionada regra de não prometer desconto, motivo: cliente reclamou..."

Próximo passo: acumule essas linhas num histórico por projeto.

PROMPT 59

Preparar um treinamento rápido pra equipe do cliente

Quando usarNa entrega final de um projeto
Preencher[COMO O AGENTE FUNCIONA]
Com base em como este agente funciona: [COMO O AGENTE FUNCIONA], escreva um guia rápido (5 passos) pra equipe do cliente saber usar e quando assumir a conversa manualmente.

Exemplo: cole o resumo do funcionamento do Bella Bot.

Próximo passo: envie junto com a entrega final.

PROMPT 60

Auditar se um agente ainda está alinhado com o negócio

Quando usarRevisão trimestral ou quando algo parecer errado
Preencher[INSTRUÇÕES ATUAIS], [SITUAÇÃO ATUAL DO NEGÓCIO]
Compare estas instruções: [INSTRUÇÕES ATUAIS] com a situação atual do negócio: [SITUAÇÃO ATUAL DO NEGÓCIO]. Aponte qualquer desalinhamento encontrado.

Exemplo: descreva como o negócio funciona hoje, mesmo que tenha mudado bastante.

Próximo passo: use os prompts de Adaptação (categoria 04) pra corrigir o que estiver desalinhado.
